# Diffractive Deep Neural Network (D2N2)

Фреймворк для проектирования и обучения дифракционных нейронных сетей на языке MATLAB. Этот проект предоставляет модульный набор классов для построения любых оптических систем с возможностью обучения через обратное распространение ошибки.
С помощью данного фреймворка можно обучать оптические системы для задач:
- классификации изображений,
- формирования изображений.
А так же моделировать уже существующие системы без обучения (например систему оптического матричного умножения).

## 2. Архитектура системы

Фреймворк использует **архитектуру цепочки** (chain pattern), где каждый компонент оптической системы содержит ссылку на предыдущий слой. Таким образом чтобы компонент мог сделать преобразование с оптическим полем он сначала запрашивает поле от предыдущего слоя, выполняет свое преобразование и отправляет следующему слою.

```
Input → ... → Propagator → DOE → Propagator → ... → Output
```

Здесь стоит обратить внимание, `Input` не имеет ссылки на предыдущей элемент, т.к. как раз он занимается формированием начального оптического поля для всей системы. Как раз параметр `input`, который передавался через всю цепочку указывает элементу `Input` как сформировать заданное поле.

В фреймворке представлены следующие базовые классы:

- `Back_Propogator` - компоненты наследующиеся от данного класса поддерживают обратное распространение ошибки.
**Методы**:
	- `need_error_field()` - `true` если данному классу (или предшествующему слою нужна ошибка для обучения), иначе `false`. (Сделано для того, чтобы не передавать ошибку до самого начала системы, если дальше она нигде не требуется).
	- `set_error_field(error)` - принимает поле ошибки.
	- `gradient_step(speed)` - обновление параметров (после того как поле ошибки прошло через всю систему и были посчитаны градиенты для обучаемых элементов - выполняет обновление параметров с заданным параметром градиентного шага).
	- `clear()` - очищает все хранящиеся данные перед следующем прогоном (сохраненное поле прямого прохождение, поля ошибки и др. необходимое для выполнения градиентного шага).

- `Encoder` - компоненты наследующиеся от данного класса могут формировать оптическое поле на выходе. Наследуется от класса `Back_Propogator`.
**Методы**:
	- `get_field(input)` - возвращает оптическое поле следующему слою.
	- `output_mesh()` - возвращает свою выходную сетку.
	- `set_output_mesh(mesh)` - позволяет установить выходную сетку (используется во время инициализации системы, когда сетка определяется будущими компонентами).

- `Opt_Input` - компоненты наследующиеся от данного класса могут принимать оптическое поле для дальнейшей обработки.
**Методы**:
	- `input_mesh()` - возвращает размер своей входной сетки.

- `Decoder` - компоненты наследующиеся от данного класса возвращают оценки от оптического поля. Наследуется от класса `Back_Propogator`.
**Методы**:
	- `get_output(input)` - возвращает оценки.
	- `count_outputs()` - говорит сколько оценок будет получено.

- `Prop` - класс предназначенный для большинства оптических элементов в системе, который объединяет классы `Encoder` и `Opt_Input`. Т.е. классы наследующиеся от `Prop` способны принимать входное поле и возвращать его дальше (при необходимости сделав некоторые преобразования).

## 3. Основные классы

### 3.1. Базовые компоненты

#### 3.1.1. `Mesh` - Координатная сетка
**Назначение:** Определяет пространственную дискретизацию слоя оптической системы.

**Параметры:**
- `pixel` - размер пикселя в метрах \[Px, Py\], так же можно использовать одно число P, которое будет конвертировано в \[P, P\].
- `N` - количество точек сетки \[Nx, Ny\], так же можно использовать одно число N, которое будет конвертировано в \[N, N\].
Здесь стоит отметить, что полный размер области по какой либо оси будет определяться как P×N с центром в 0. Далее полный размер делится на N ячеек, и узлы соответствуют центрам каждой ячейки.
Здесь так же стоит обратить внимание, что координатная ось X является вертикальной с положительным направлением вниз ↓, а координатная ось Y горизонтальной с положительным направлением вправо →.

**Методы:**
- `Mesh.X` - координаты по оси X (Nx × 1);
- `Mesh.Y` - координаты по оси Y (1 × Ny);
- `offset(off)` - сдвиг сетки на вектор `off = [offx, offy]`, так же можно использовать одно число `off`, которое будет конвертировано в `[off, 0]`;
- `size()` - возвращает размеры сетки.

**Пример:**
```matlab
% Сетка 512×512 с размером пикселя 4 микрона
mesh = Mesh(4e-6, 512);

% Сетка 2048×512 с разными размерами пикселей
mesh = Mesh([2e-6, 4e-6], [2048, 512]);
```


#### 3.1.2. Оптимизаторы
**Назначение:** Задают каким образом будет производиться оптимизация оптических элементов (различным элементам можно задавать различные оптимизаторы, если не задавать никакой оптимизатор, то элемент будет считаться статическим и не будет обучаться).

В данном фреймворке реализованы следующие оптимизаторы:
- `SGDOptimizer` - Стохастический градиентный спуск.
- `NesterofOptimizer` - Оптимизатор импульса (задает градиенту некоторый импульс, оптимальный параметр импульса `viscosity = 0,9`).
- `AdagradOptimizer` - Adaptive gradient (адаптивно увеличивает или уменьшает шаг для весов, оптимальный параметр `eps = 1e-8`).
- `RMSpropOptimizer` - Продвинутая версия Adagrad (оптимальные параметры `accumulater = 0,999`, `eps = 1e-8`)
- `AdamOptimizer` - Adaptive moment estimation (наиболее популярный оптимизатор, которым скорее вы буде пользоваться всегда, объединяет идеи оптимизаторов Nesterof и RMSprop. Оптимальные параметры `viscosity = 0,9`, `accumulater = 0,999`, `eps = 1e-8`).
Более подробно про оптимизаторы можно прочитать в следующей [статье](https://habr.com/ru/articles/318970/).
Все ранее перечисленные оптимизаторы наследуются от класса `Optimizer`, который задает следующие методы:
- `optimize(gradient)` - провести оптимизацию с полученным градиентом.
- `reset()` - обнуляет состояние оптимизатора.

Однако сам оптимизатор задается в обучаемом элементе не напрямую, а через соответствующую фабрику:
- `SGDFabric` - не принимает параметров.
- `NesterofFabric` - принимает параметр `viscosity` (если параметр не передавать по умолчанию будет установлен `0,9`).
- `AdagradFabric` - принимает параметр `epsilon` (если параметр не передавать по умолчанию будет установлен `1e-8`).
- `RMSpropFabric` - принимает параметры `accumulater` и `epsilon` (если параметры не передавать по умолчанию будут установлены `0,999` и `1e-8` соответственно).
- `AdamFabric` - принимает параметры `viscosity`, `accumulater` и `epsilon` (если параметры не передавать по умолчанию будут установлены `0,9`, `0,999` и `1e-8` соответственно).
Так же данные фабрики реализуются от базового класса `OptimizerFabric`, который задает метод:
- `generate(mesh)` - создание соответствующего оптимизатора под заданную сетку.


### 3.2. Компоненты оптической системы

#### 3.2.1. `InputModulator` - Модулятор входного поля
**Назначение:** Начальный слой, который преобразует входные данные в оптическое поле.
Наследуется от класса `Encoder`.

**Параметры:**
- `Mesh` - сетка входного слоя.
- `Func` - функция преобразования входных данных (опционально, если функция не будет передана, то параметр input будет считаться тем самым входным полем).

**Пример:**
```matlab
% Входной модулятор с нормализацией поля
dc = InputModulator(mesh_inp, @(W)normalize_field(W));

% Входной масштабирующей поле в 4 раза
dc = InputModulator(mesh_inp, @(W)repelem(W,4,4));

% Входной модулятор возвращающий всегда одно и то же поле
dc = InputModulator(mesh_inp, @(W)exp(-(mesh_inp.X.^2 + mesh_inp.Y.^2)/2/sig^2));
```

**Примечание**: Первые два индекса используются для кодирования пространственных координат узлов поля. По третьему индексу располагаются различные изображения в батче. Четвертый и большии индексы не используются, но в них тоже можно закодировать некоторые параметры, и при подсчете выходного поля они будут просуммированы.
#### 3.2.2. Распространение в свободном пространстве
**Назначение:** Классы наследующиеся от `FreePropagator` предназначены для того, чтобы выполнять оператор распространения оптического поля в свободном пространстве.
Наследуется от класса `Prop`.

**Параметры**:
- `prev_node` - предыдущий слой.
- `wavelength` - длина волны излучения.
- `distance` - расстояние распространения.

##### 3.2.2.1. `ASMPropagator` - Angular Spectrum Method
**Назначение:** Быстрое распространение волны через Фурье-преобразование в свободном пространстве.
Наследуется от класса `FFTLikePropagator`.

**Параметры:**
- `prev` - предыдущий слой.
- `distance` - расстояние распространения.
- `wavelength` - длина волны.
Данный класс не принимает на вход параметр сетки, т.к. берет её у предыдущего слоя.

**Особенности:**
- Очень быстрый благодаря FFT.
- Точный в ближней зоне.
- Сохраняет размер сетки (Размеры входной и выходной сетки должны быть одинаковыми).
- Имеет свойство наложения (поле уходя за границы не исчезает, а возвращается с противоположной стороны, из-за чего могут наблюдаться эффекты наложения поля с самим собой). Здесь предполагается, что автор сам должен подобрать такие параметры системы, чтобы избежать этого наложения.

**Пример:**
```matlab
lambda = 532e-9;  % длина волны 532 нм
f = 0.01;         % расстояние 1 см

dc = InputModulator(mesh_inp, @(W)normalize_field(W));
dc = ASMPropagator(dc, f, lambda);
```

##### 3.2.2.2. `SincPropagator` - Sinc-интерполяционное распространение
**Назначение:** Точное распространение волны на расстояние `distance` в свободном пространстве.
Наследуется от классов `FreePropagator` и `MatrixPropagator`.

Процесс распространения описывается как умножение исходного поля на матрицы распространения слева и справа:
```
Field_out = Left * Field_in * Right;
```
Генерация матриц `Left` и `Right` происходит в момент, когда сетка на входе и на выходе становятся определенными.

**Параметры:**
- `prev` - предыдущий слой.
- `distance` - расстояние распространения (в метрах).
- `wavelength` - длина волны света (в метрах).
Данный класс не принимает на вход параметры сетки, т.к. берет её у предыдущего и следующего слоев.

**Особенности:**
- Использует sinc-интерполяцию для высокой точности.
- Может иметь различные сетки на входе и на выходе.
- Медленнее чем ASMPropagator, но более точен для малых расстояний.
- Отсутствуют эффекты наложения (поле выходящее за границы сетки - пропадает).

**Пример:**
```matlab
lambda = 532e-9;  % зелёный свет
f = 0.01;         % расстояние 1 см

dc = InputModulator(mesh_inp, @(W)normalize_field(W));
dc = SincPropagator(dc, f, lambda);

% В случае когда есть несколько sinc пропагаторов с одинаковыми параметрами (входная и выходная сетки, расстояние, длина волны),
% то чтобы заново не генерировать одни и те же матрицы распространения, можно их скопировать из другого sinc пропагатора
dc = SincPropagator(dc, other); % где other ссылка на другой SincPropagator
```

Более подробно про данный метод распространения поля можно прочитать в [статье](https://opg.optica.org/josaa/abstract.cfm?uri=josaa-39-8-1403).

#### 3.2.3. `DOE` - Базовый класс дифракционных оптических элементов (ДОЭ)
**Назначение:** Определяет интерфейс для всех дифракционных элементов. Как раз объекты этого класса могут быть обучаемыми.
Наследуется от класса `Prop`.

Объекты данного класса являются промежуточными слоями и все воздействие на оптическое излучение сводится к поэлементному умножения комплексной амплитуды падающего пучка, на функцию комплексного пропускания ДОЭ.

**Методы**:
- `get_transmission_function()` - получить функцию комплексного пропускания.
- `set_inaccuracy(inaccuracy)` - установить погрешность.
- `clear_inaccuracy(index)` - удалить погрешность (если `index` не указывать - удалит все погрешности).

##### 3.2.3.1. `FullDOE` - Полностью обучаемый дифракционный элемент
**Назначение:** Основной слой нейронной сети, все параметры которого обучаются.
Наследуется от класса `DOE`.

**Параметры:**
- `prev` - предыдущий слой.
- `Mesh` - сетка элемента.
- `type` - тип данных DOE (`PhaseType`, `AmplitudeType`, и т.д.).
- `optimizer_fabric` - фабрика оптимизатора (опционально).

**Методы:**
- `set_data(data)` - установить начальные параметры.
- `set_mask(mask)` - установить маску обучаемости (0 = не обучать, 1 = обучать).
- `imagesc()` - визуализировать элемент.

**Пример:**
```matlab
% Создать обучаемый фазовый дифракционный элемент
dc = FullDOE(dc, mesh, PhaseType, AdamFabric());

% С маской: обучать только центральную часть
mask = zeros(size(mesh));
mask(100:400, 100:400) = 1;
dc = FullDOE(dc, mesh, PhaseType, AdamFabric()).set_mask(mask);

% Начальные значения: линза
phase_init = -2*pi/lambda/f/2*(mesh.X.^2 + mesh.Y.^2);
dc = FullDOE(dc, mesh, PhaseType, AdamFabric()).set_data(phase_init);
```

##### 3.2.3.2. `CylindricalDOE` - Цилиндрический дифракционный элемент
**Назначение:** Разделяемый элемент, действующий независимо на X или Y координату. Используется для реализации цилиндрических линз.
Наследуется от классов `DOE` и `MatrixPropagator`.

**Параметры:**
- `prev` - предыдущий слой.
- `Mesh` - сетка элемента.
- `type` - тип данных DOE.
- `direction` - направление ("X" или "Y").
- `optimizer_fabric` - фабрика оптимизатора (опционально).

**Пример:**
```matlab
% Реализовать цилиндрическую линзу с фокусным расстоянием f
dc = CylindricalDOE(dc, mesh, PhaseType, "X").set_data(-2*pi/lambda/f/2*mesh.X.^2);
```

#### 3.2.4. `DataType` - Базовый класс типов данных ДОЭ
**Назначение:** Определяет тип данных обучаемых параметров ДОЭ, будь то фазовые значения, амплитудные и др.

На текущий момент в фреймворке реализуются 3 следующих типа:

##### 3.2.4.1. `PhaseType` - Фазовый ДОЭ
ДОЭ с фазовым типом модулирует только фазовую составляющую светового поля, оставляя амплитуду нетронутой.
Функция пропускания ДОЭ будет иметь следующий вид:
```
TF = exp(i * phi),
```
где `phi` - фаза ДОЭ, которая является обучаемым параметром и может принимать любые действительные значения.

##### 3.2.4.2. `AmplitudeType` - Амплитудный ДОЭ
ДОЭ с амплитудным типом модулирует только амплитудную составляющую светового поля, оставляя фазу нетронутой, здесь стоит обратить внимание, что амплитуда может принимать значения в диапазоне от 0 до 1.
Функция пропускания ДОЭ будет иметь следующий вид:
```
TF = sigmoid(theta),
```
где `theta` - параметр ДОЭ, который является обучаемым и может принимать любые действительные значения.
Функция `sigmoid` - это функция сигмойды для ограничения функции пропускания в диапазоне от 0 до 1 и определяется следующим образом:
```
y = 1/(1 + exp(-x));
```
Здесь стоит обратить внимание, что вызывая у ДОЭ функцию `set_data(data)` необходимо передавать начальное значение уже нормированное от 0 до 1, далее данный тип конвертирует его в `theta`.

##### 3.2.4.3 `ComplexType` - Комплексный ДОЭ
ДОЭ с комплексным типом в качестве функции пропускания имеет комплексное число. Такой ДОЭ может модулировать как амплитудную составляющу, так и фазовую. При этом амплитуда не ограничена диапазоном от 0 до 1, а может принимать любое значение.
Функция пропускания ДОЭ будет иметь следующий вид:
```
TF = a + i*b
```
где `i` - мнимая единица, а `a` и `b` - обучаемые параметры ДОЭ (действительная и мнимая составляющие), которые принимают любое действительное значение.

#### 3.2.5. `GetOutput` - Получение выходных данных
**Назначение**: Выходной слой оптической системы. Получает оптическое поле с предыдущего слоя и преобразует в итоговые оценки.
Наследуется от `Decoder` и `Opt_Input`.

**Методы**:
- `intensity(input)` - получает интенсивность (квадрат амплитуды) оптического поля.
- `get_output(input)` - получение выходных оценок. Здесь первый индекс массива отвечает за номер оценки, а второй индекс за номер изображения в батче.

##### 3.2.5.1 `GetFullIntensity` - Полная интенсивность поля
**Назначение:** Вычислить интенсивность на выходе системы. Делает развертку всего оптического поля и каждый узел поля становится оценкой. Обычно предназначается для задачи формирования изображений или для того, чтобы просто посмотреть, какой выход даёт система.
Наследуется от `GetOutput`.

**Пример:**
```matlab
dc = SincPropagator(dc, f, lambda);
dc = GetFullIntensity(dc, mesh);

% Так же есть возможноть задать маску
dc = GetFullIntensity(dc, mesh, MASK);
```

##### 3.2.5.2 `GetMaskOutput` - Получить оценки в масках
**Назначение:** Посчитать поле в заданных масках. Каждой оценке соответствует своя маска.
Наследуется от `GetOutput` и `Predictor`.

Параметры:
- `Mask` - маски. Первые два индекса отвечают за пространственные координаты, третий индекс за номер маски. Количество оценок на выходе равно количеству масок.

##### 3.2.5.3 `GetMaskSum - Получить оценки в масках
**Назначение:** Считаем суммарную интенсивность в масках.
Наследуется от `GetMaskOutput`.

**Пример:**
```matlab
% Маска для 10 квадратных детекторов
MASK = mask10_1(mesh, [1.2e-3, 0.9e-3], 100e-6);
dc = GetMaskSum(dc, mesh, MASK);
```

##### 3.2.5.4 `GetMaskMax - Получить оценки в масках
**Назначение:** Считаем максимальную интенсивность в масках.
Наследуется от `GetMaskOutput`.

**Пример:**
```matlab
% Маска для 10 квадратных детекторов
MASK = mask10_1(mesh, [1.2e-3, 0.9e-3], 100e-6);
dc = GetMaskMax(dc, mesh, MASK);
```

### 3.3. Компоненты декодера

#### 3.3.1. `NormalizationMAX` - Нормализация через максимум
**Назначение:** Нормализует оценки по максимальному значению среди всех оценок.
Наследуется от `Decoder` и `Predictor`.

**Пример:**
```matlab
dc = GetMaskSum(dc, mesh, MASK);
predictor = NormalizationMAX(dc);
```

#### 3.3.2. `NormalizationSUM` - Нормализация через сумму
**Назначение:** Нормализует оценки по суммарному значению от всех оценок.
Наследуется от `Decoder` и `Predictor`.

**Пример:**
```matlab
dc = GetOutput(dc, mesh);
dc = NormalizationSUM(dc);
```

#### 3.3.3. `ScoreSpliter` - Делитель оценок
**Назначение:** Некоторый промежуточный слой с помощью которого оценки можно делить между разными частями системы, например задав две функции ошибки с разными параметрами, а для получения единой ошибки просуммировать эти две ошибки с различными весами.

**Пример:**
```matlab
dc = GetMaskSum(dc, mesh, MASK);
dc = ScoreSpliter(dc);
err1 = ErrorSCE(dc, ...);
err2 = ErrorMSE(dc, ...);
Error = ErrorSUM(err1, 0.5);
Error.add_new(err2, 0.5);
```

Для чего нужен этот элемент и почему просто нельзя эти две функции ошибки взять от `GetMaskSum`?
Данный элемент не отправляет сразу поле ошибки на предыдущий слой, как только получил его. Он дожидается когда все последующие слои пришлют свои ошибки, просуммирует их и только после этого отправит в предыдущий слой. Это нужно для избежания повторного отправления ошибки через систему, что экономит ресурсы и время работы системы.

### 3.4. Функции ошибок

### 3.4.1. Целевые функции

Перед введением функции ошибки необходимо изначально ввести целевую функцию.
Целевая функция показывает к каким распределениям оценок должен стремиться декодер. Декодер возвращает двумерный массив, где первый индекс отвечает за номер оценки, а второй для изображений в батче. У каждого исходного изображения есть принадлежность к определенному классу и к какому классу принадлежит это изображение определяется массивом с метками. Поэтому для каждого класса необходимо ещё задать целевое распределение оценок, к которому будет стремиться обучаться оптическая система.

Базовый класс `GetTarget` имеет следующий метод:
- `get_target(index)` - который возвращает вектор целевых оценок для класса `index`. В качестве `index` можно передать вектор классов, равный длине батча, чтобы сразу получить матрицу целевых оценок соответствующий батчу изображений, тогда первый индекс будет отвечать за номер оценки, а второй за номер изображения в батче.

Для задачи классификации распознанным классом будет считаться то изображение, оценка которого достигла максимального значения, поэтому в качестве целевых оценок будет считаться вектор, у которого стоит `1` в номере соответсвующего класса и `0` во всех остальных элементах.

Класс `ClassificationTarget` наследующийся от `GetTarget` предназначен для задачи классификации и принимает следующие параметры параметры:
- `count_output` - количество выходных оценок,
- `count_class` - количество классов классификации.
И генерирует единичную матрицу. Поэтому для `i`-того класса будет максимизироваться `i`-тая оценка.

**Примечание**: Обратите внимание, что перед подачей оценок в функцию ошибок рекомендуется сначала нормировать оценки одним из ранее предложенных способов.

Класс `GenerationTarget` наследующийся от `GetTarget` принимает параметры:
- `images` - одно или несколько целевых изображений. Первые два индекса отвечают за пространственные координаты изображения, а третий за номер изображения.
В такой класс можно передать только одно изображение и тогда любое входное распределение будет стремиться генерировать данное распределение. Или можно передать набор изображений (в количестве сколько всего классов изображений) и тогда каждый класс будет пытаться генерировать свое изображение.
Так же стоит обратить внимание, что `images` - это желаемое распределение интенсивности (т.е. квадрата модуля оптического поля).

**Примечание**: Так же рекомендуется произвести нормировку выходных оценок и целевых изображений `images`.

**Пример:**
```matlab
% Оценки для классификации изображений
target = ClassificationTarget(10, 10); % 10 оценок на выходе и 10 классов
target = ClassificationTarget(decoder.count_outputs(), length(unique(TrainLabel))); % автоматически определяет количество оценок на выходе и колличество классов изображений

% Оценки для генерации изображений
Images(:,:,1) = ...
Images(:,:,2) = ...
...
Images = Images./sum(Images, [1 2]);
target = GenerationTarget(Images);
```

#### 3.4.2. `ErrorFunction` - Базовый класс для функций ошибок
**Назначение:** конвертирует распределение оценок в единое число "ошибку", которую дальше необходимо минимизировать.

**Методы:**
- `get_error(input, index)` - получает оценку из текущего входа `input` и индекса класса изображений `index`.
- `minimize(speed, weight)` - проводит минимизацию параметров с заданным шагом `speed` и весом `weight` (если `weight` не передавать, он будет равен 1).

##### 3.4.2.1. `ErrorSum` - Суммарная ошибка
**Назначение:** суммирует ошибки других функций ошибок с заданными весами.
Наследуется от `ErrorFunction`.

В конструкторе принимает `error` - функцию ошибки; `weight` - вес с которым эта ошибка будет суммироваться.
Добавление других функций ошибок осуществляется через метод `add_new(error, weight)`, который принимает те же параметры, что и конструктор.

**Пример:**
```matlab
Error = ErrorSUM(err1, 0.4);
Error.add_new(err2, 0.1);
Error.add_new(err3, 0.5);
```
**Примечание**: Не обязательно сумма весов должна равняться 1.

##### 3.4.2.2. `ErrorJSCE` - Функция ошибки Joint Softmax Cross Entropy
**Назначение:** Предназначена для классификации изображений с дополнительной максимизацией энергии по целевым областям.
Наследуется от `ErrorFunction`.

**Параметры:**
- `decoder` - декодер из которого берутся оценки.
- `target` - целевые оценки.
- `alpha` - температурный параметр (см. Функция ошибки SCE).
- `beta` - коэффициент объединения.

В данную функцию ошибки нужно передавать **не нормированные** оценки. Т.к. данная функция как раз делит оценки на 2 части:
- Первая часть нормируется по максимуму и передается в `ErrorSCE` вместе с температурным параметром `alpha`.
- Вторая часть передается в функцию максимизации энергии `ErrorPEF`.
Далее обе части объединябтся в единую ошибку с коэффициентом `beta`:
```
Error = beta * ErrorPEF + (1 - beta) * ErrorSCE
```

В качестве параметра `beta` рекомендуется брать значения 0,1-0,2. Более подробно про данную функцию ошибки смотрите в [статье](https://opg.optica.org/oe/fulltext.cfm?uri=oe-33-4-7307).

##### 3.4.2.3. `Error_Decoder` - Базовый класс для элементарных функций ошибок
**Назначение:** является базовым классом для основных функций ошибок. Получает ошибку из полученных оценок и целевых оценок.
Наследуется от `ErrorFunction` и `Predictor`.

##### 3.4.2.4. `ErrorMAE` - Средне абсолютная ошибка
Наследуется от `Error_Decoder`.

Рассчитывает оценку по следующей функции:
```
Error = sum(abs(score - target))
```

##### 3.4.2.5. `ErrorMSE` - Средне квадратичная ошибка
Наследуется от `Error_Decoder`.

Рассчитывает оценку по следующей функции:
```
Error = sum((score - target)^2)
```

##### 3.4.2.6. `ErrorSCE` - Перекрестная энтропия
Наследуется от `Error_Decoder`.

Принимает параметр `alpha` - температурный коэффициент.
Рекомендуется брать от 20 до 80 при нормировку по сумме и 10 классах изображений.

Рассчитывает оценку по следующей функции:
```
p = exp(score * alpha)
Error = -sum( target * log(p / sum(p)) )
```

##### 3.4.2.7. `ErrorPEF` - Функция энергетической эффективности
Предназначена для повышения всех оценок разом, для максимизации попадания излучения в целевые области. Сама по себе не годится для классификации, а работает только в связке с другими функциями ошибки. Более подробно про данную функцию ошибки смотрите в [статье](https://opg.optica.org/oe/fulltext.cfm?uri=oe-33-4-7307).
Наследуется от `Error_Decoder`.

Принимает параметр `InputEnergy`, который указывает сколько энергии подается на вход системы. По умолчанию принимает 1 (как раз подходит, если применить функцию нормировки входного изображения).

Рассчитывает оценку по следующей функции:
```
Error = -log(sum(score) / InputEnergy)
```

### 3.5. Другие полезные функции

#### 3.5.1. `CompiledMatrixPropagator` - Композитный распространитель
**Назначение:** Объединяет матричные операторы распространения в один оператор для оптимизации программы.
Наследуется от `MatrixPropagator`.

Некоторые операторы распространения работают по принципу умножения матриц слева и/или справа на исходное поле, такие как `SincPropagator` и `CylindricalDOE`.
Операторы работающие по данному принципу реализуют интерфейс `MatrixPropagator`, который имеет два метода:
- `get_left()` - получить левую матрицу.
- `get_right()` - получить правую матрицу.

Каждый такой оператор преобразует оптическое поле следующим образом:
```
W_out = Left * W_in * Right
```

Тогда каскад таких операторов будет иметь следующее преобразование:
```
W_out = Ln * ... * L2 * L1 * W_in * R1 * R2 * ... * Rn
```

Не сложно заметить, что такой каскад можно упростить следующим образом:
```
L = Ln * ... * L2 * L1
R = R1 * R2 * ... * Rn

W_out = L * W_in * R
```

Таким образом оператор `CompiledMatrixPropagator` занимается такой оптимизацией. При такой оптимизации нужно обратить внимание на следующие детали:
- Все входящие в него операторы должны работать через матричное умножение (т.е. тоже наследоваться от `MatrixPropagator`).
- Нельзя поставить в него оптимизируемые элементы (точнее можно, но они не будут оптимизироваться).
- Нельзя декомпозировать данный оператор обратно на отдельные составляющие.

В конструкторе данный оператор принимает предыдущий слой `prev` (и может ещё принимать другой `MatrixPropagator`, из которого скопирует матрицы распространения, для этого необходимо, чтобы входные сетки совпадали).
Для добавления операторов в оптимизацию нужно добавлять их через метод `add_next(operator)`. При этом при инициализации операторов, которые будут оптимизированы, в них нужно передавать ссылку на сам оператор оптимизации `CompiledMatrixPropagator`.

Данную оптимизацию уместно применять в 4F системах, т.к. линзы там можно представить в факторизированном виде.
```matlab
% Без оптимизации
dc = SincPropagator(dc, f, lambda);
dc = FullDOE(dc, mesh, PhaseType).set_data(-2*pi/lambda/f/2*(mesh.X.^2 + mesh.Y.^2));
dc = SincPropagator(dc, f, lambda);

% С оптимизацией
dc = CompiledMatrixPropagator(dc);
dc.add_next(SincPropagator(dc, f, lambda));
dc.add_next(CylindricalDOE(dc, mesh, PhaseType, "X").set_data(-2*pi/lambda/f/2*mesh.X.^2));
dc.add_next(CylindricalDOE(dc, mesh, PhaseType, "Y").set_data(-2*pi/lambda/f/2*mesh.Y.^2));
dc.add_next(SincPropagator(dc, f, lambda));
```

#### 3.5.2. `BeamSplitter` - Делитель пучка
**Назначение:** делит пучок в разные выходы. Работает по аналогии со `ScoreSplitter`, но делит не оценки, а оптическое поле.
Наследуется от `Prop`.

На вход принимает ссылку на предыдущий `prev` слой и сетку `mesh`.

**Пример:**
```matlab
dc = BeamSplitter(dc, mesh);
dc1 = ASMPropagator(dc, f1, lambda);
dc2 = SincPropagetor(dc, f2, lambda);
```

### 3.6. Погрешности ДОЭ

Дифракционные оптические элементы могут изготавливаться и размещаться в системе с погрешностями. Поэтому иногда возникает необходимость моделировать оптическую систему с учетом таких погрешностей и даже обучать оптические элементы так, чтобы они были устойчивы к таким погрешностям.
В данном фреймворке реализованы возможности работы с некоторыми видами погрешностей.

Все погрешности реализуют базовый класс `Inaccurasy` который имеет следующие методы:
- `enable()` - включает погрешность (по умолчанию погрешность включена).
- `disable()` - выключает погрешность.
- `apply(transmission_fanction)` - вносит погрешность в функцию пропускания.
- `get_gradient(gradient)` - получает градиент с учетом погрешности.

В фреймворке реализованы следующие виды погрешностей:

#### 3.6.1. `Inaccr_shift` - Погрешность смещения
**Назначение:** Погрешность смещения ДОЭ от центральной оси.
Наследуется от `Inaccurasy`.

При создании в конструкторе указывается максимальное смещение в пикселях `max_shift`. Для обоих осей при каждом новом прогоне будет генерироваться смещение от `-max_shift` до `max_shift` включительно. Смещение ДОЭ выполняется циклическим сдвигом. После процесса обучения погрешность сбрасывается и начинается все сначала.

Методы:
- `set_fixed_shift(shift)` - устанавливает фиксированное смещение (другие значения смещений генерироваться не будут). Предназначен для тестирования результатов при фиксированном смещении.
- `clear_fixed_shift()` - очищает фиксированное смещение. Переходит в режим случайных смещений.

#### 3.6.2. `Inaccr_noise` - Погрешность шума
**Назначение:** Базовый класс для задания погрешности в виде шума.
Наследуется от `Inaccurasy`.

#### 3.6.3. `Inaccr_uniform_phase_noise` - Фазовый шум
**Назначение:** Генерирует равномерный фазовый шум.
Наследуется от `Inaccr_noise`.

В конструкторе задается порог максимального шума `max_noise`. Фазовый шум будет генерироваться в диапазоне от `0` до `max_noise`.

#### 3.6.4. `Inaccr_uniform_amplitude_noise` - Амплитудный шум
**Назначение:** Генерирует равномерный амплитудный шум.
Наследуется от `Inaccr_noise`.

В конструкторе задается порог максимального шума `max_noise`. Амплитудный шум будет генерироваться в диапазоне от `1-max_noise` до `1`.

#### 3.6.5. `Inaccr_smooth` - Погрешность сглаживания
**Назначение:** Базовый класс для задания погрешности сглаживания функции пропускания.
Наследуется от `Inaccurasy`.

В конструкторе принимает параметр `phace_only`, который устанавливается в `true` чтобы данная погрешность не изменяла значения амплитудной пропускаемости, а влияла только на фазу. По умолчания `phase_only` установлена в `false`.

#### 3.6.6. `Inaccr_smooth_gaussian` - Сглаживание по Гауссу
**Назначение:** Сглаживает функцию пропускания по Гауссову ядру.
Наследуется от `Inaccr_smooth`.

В конструкторе принимает значения размера ядра `size` и величины рассеянности ядра `deviation`.

#### 3.6.7. `Inaccr_smooth_rectangle` - Сглаживание по прямоугольной функции
**Назначение:** Сглаживает функцию пропускания по прямоугольному ядру.
Наследуется от `Inaccr_smooth`.

В конструкторе принимает значения размера ядра `size`.

---

**Примеры:**
```matlab
dc = FullDOE(dc, mesh, PhaseType, AdamFabric());

% Создаем погрешности
inac1 = Inaccr_shift(2);
inac2 = Inaccr_smooth_gaussian(3, 1, 0.5, true);
inac3 = Inaccr_uniform_phase_noise(pi/4);

% Добавляем погрешности к элементу
dc.set_inaccurasy(inac1);
dc.set_inaccurasy(inac2);
dc.set_inaccurasy(inac3);
```
Обратите внимание, что погрешности будут применяться в том порядке в котором вы их добавили в элемент. Это важно т.к. сначала будет применена погрешность сглаживания и только потом добавиться шум. А иначе бы сначала добавился шум и потом он сгладился вместе с функцие пропускания.

Погрешности являются ссылочными типами, поэтому их можно отключить легко отключить:
```matlab
inac2.disable();
inac3.disable();
inac1.set_fixed_shift([1 0]);
```

А так же удалить из ДОЭ по индексу или все разом:
```matlab
dc.clear_inaccurasy(1); % удалить погрешность смещения
dc.clear_inaccurasy();  % удалить все погрешности
```

## 4. Обучающие и тестовые выборки

В данном фреймворке уже предзагружены базовые обучающие и тестовые выборки: MNIST, FasionMNIST, EMNIST.
Чтобы загрузить одну из перечисленных выборок достаточно вызвать следующий скрипт:
- `mnist_digits` - загружает датасет рукописных цифр MNIST.
- `fashion_mnist` - загружает датасет элементов одежды Fashion MNIST.
- `emnist` - загружает датасет рукописных букв EMNIST.

При загрузке датасета будут доступны следующие переменные:
- `Train` - трехмерный массив обучающий выборки. Первые 2 измерения - пространственные координаты, третье измерение номер изображения.
- `TrainLabel` - метки изображений. Первое измерение равно 1, второе измерение указывает принадлежность к классу соответствующего изображения из `Train` (от `1` до `N`, где `N` - количество классов).
- `Test` - трехмерный массив тестовой выборки. Аналогично `Train`.
- `TestLabel` - метки изображений тестовой выборки. Аналогично `TrainLabel`.
- `Labels` - названия классов (cell массив где `i`-тый элемент является строкой с названием `i`-того класса).

Так же в фреймворке предоставлены функции для создания целевых масок для считывания изображений на выходе:
- `mask2(mesh, distance, mask_size)` - создает 2 маски для бинарной классификации. `mask_size` указывает размер маски, `distance` - расстояние между масками, `mesh` - сетка на выходе.

- `mask10_1(mesh, full_rect, mask_size)` - создает 10 масок для классификации цифр или элементов одежды. Маски располагаются по контуру прямоугольника со сторонами `full_rect`, размер масок задается `mask_size`, `mesh` - сетка на выходе.

- `mask10_2(mesh, full_rect, mask_size)` - создает 10 масок для классификации цифр или элементов одежды. Маски располагаются в прямоугольнике со сторонами `full_rect` (3 сверху, 4 по центру, 3 снизу), размер масок задается `mask_size`, `mesh` - сетка на выходе.

- `mask26(mesh, full_rect, mask_size)` - создает 26 масок для классификации рукописных букв. Маски располагаются в прямоугольнике со сторонами `full_rect` (Со следующем количеством масок в рядах (сверху вниз): 6, 7, 7, 6), размер масок задается `mask_size`, `mesh` - сетка на выходе.

## 5. Обучение и тестирование

### 5.1. Обучение

После того как система была сконструирована пора переходить к обучению. Для этого используется скрипт `training1.m`, для которого необходимо определить следующие параметры:
- `Train` - обучающая выборка (обязательный параметр).
- `TrainLabel` - метки обучающей выборки (обязательный параметр).
- `Error` - функция ошибки для минимизации (обязательный параметр).
- `epoch` - количество эпох (по умолчанию = 1).
- `speed` - начальная величина шага (обязательный параметр).
- `slowdown` - геометрическое уменьшение шага на каждой итерации (по умолчанию = 1).
- `batch` - размер батча (по умолчанию = 1).
- `max_batch` - если батч слишком большой, чтобы уместиться в память, то `max_batch` размер подбатча, которые сначала прогоняются через систему, а потом уже выполняется градиентный шаг (по умолчанию = `batch`).
- `cycle` - указывает раз в сколько итераций нужно выводить данные в консоль (по умолчанию равен обучающей выборке).
- `is_backup` - указывает стоит ли во время обучения периодически сохранять данные (по умолчанию = `false`).
- `backup_time` - раз в сколько времени делать бэкап в секундах (по умолчанию = 3600 с (1 час)).
- `predictor` - если решаем задачу классификации то чтобы во время обучения выводилась информация о текущей точности системы в качестве `predictor` передается элемент реализующий класс `Predictor` (не обязательный параметр, если задавать, то просто не будет выводиться информация о точности системы).

Определив необходимые параметры можно переходить к обучению:
```matlab
dc = GetMaskSum(dc, mesh, MASK); decoder = dc; predictor = dc;
Error = ErrorJSCE(dc, ClassificationTarget(dc.count_outputs(), length(unique(TrainLabel))), 20, 0.1);

epoch = 4;
batch = 20;
cycle = 6000;
speed = 0.3;
slowdown = 0.9995;
training1;
```

### 5.2. Тестирование

Тестирование обученной системы проводится с помощью скрипта `check_result.m`, для которого необходимо определить следующие параметры:
- `Test` - тестовая выборка (обязательный параметр).
- `TestLabel` - метки тестовой выборки (обязательный параметр).
- `decoder` - декодер из которого будут получаться оценки системы (обязательный параметр).
- `max_batch` - размер батча (по умолчанию = 40).

```matlab
max_batch = 20;
check_result;
```

После окончания тестирования в консоль будут выведены значения общей точности (количество правильно классифицированных изображений к общему количеству изображений в тестовой выборке), и значение минимального контраста (показывает насколько много в среднем энергии попадало в заданную область по отношению к другим областям).

Так же в файле `check_result.m` есть секции с помощью которых можно вывести оформленные таблицы точности и контраста.

### 5.3. Тестирование смещений

В случае, если система обучалась с погрешностями смещений, то можно провести тестирование системы при различных смещениях. Для этого используйте скрипт `check_offsets.m`, для которого нужно определить следующие параметры:
- `max_offsets` - будет проводить тестирование для всех возможных смещений в диапазоне \[`-max_offsets`, `max_offsets`\].
- `test_doe` - ссылка на погрешность смещения которую необходимо тестировать.
Для получения корректных результатов не забудьте выключить погрешности в других ДОЭ.

```matlab
test_doe = doe.Errors{1}; % Если погрешность смещения задавалась первой
max_offsets = 2;
check_offsets;
```

В данном скрипте так же есть секции для вывода оформленных таблиц точности и контраста для проверенных смещений.

### 5.4. Вывод результатов

Для вывода результатов работы ДОЭ воспользуйтесь скриптом `print_result.m`, для которого нужно определить следующие параметры:
- `Size` - количество случайных выводимых изображений из тестовой выборки (по умолчанию = 10).
- `delay` - задержка между показом изображений (по умолчанию = 3 с).
- `decoder` - декодер, который является `Opt_Input` и `Decoder`, для показа изображений и получения оценок.

## 6. Пример построения системы

```matlab
clear all;                                           % очистка рабочего пространства

% задаем необходимые параметры
mnist_digits;                                        % загружаем датасет цифр
global is_gpu; is_gpu = true;                        % устанавливаем работу через GPU
lambda = 632.8e-9;                                   % длина волны будет 632,8 нм
f = 0.01;                                            % расстояние между плоскостями будет 1 см
mesh = Mesh(4e-6, 512);                              % все сетки будут 512x515 пикселей с размером пикселя 4 мкм
mesh_inp = Mesh(8e-6, 28);                           % входная сетка будет иметь размер 28x28 пикселей (как раз размер изображений) с размерм пикселя 8 мкм
opt = AdamFabric();                                  % оптимизатор будет Adam
MASK = mask10_1(mesh,[1.2e-3, 0.9e-3],100e-6);       % создаем маски

% теперь идет построение системы
dc = InputModulator(mesh_inp, @(W)normalize_field(W));                                                  % входной модулятор
dc = SincPropagator(dc, f, lambda);                                                                     % распространение по sinc на расстояние f
dc = FullDOE(dc, mesh, PhaseType, opt); doe = dc;                                                       % фазовый ДОЭ
dc = ASMPropagator(dc, f, lambda);                                                                      % распространение ASM на расстояние f
dc = GetMaskSum(dc, mesh, MASK); decoder = dc; predictor = dc;                                          % выходной модулятор. считываем сумму в областях
Error = ErrorJSCE(dc, ClassificationTarget(dc.count_outputs(), length(unique(TrainLabel))), 20, 0.1);   % функция ошибки JSCE

% проводим обучение
epoch = 4;            % ставим 4 эпохи
batch = 20;           % 20 изображений в батче
cycle = 6000;         % вывод информации в консоль наждые 6000 изображений
speed = 0.3;          % начальная скорость 0.3
slowdown = 0.9995;    % уменьшение шага после каждого батча в 0.9995
training1;            % запуск обучения

% проводим тестирование
check_result;
```
